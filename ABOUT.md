# О проекте

## Назначение

МИСМ МЧС предназначен для централизованного мониторинга объектов и координации реагирования на инциденты. Система объединяет IoT-устройства, карту обстановки и роли пользователей в единую оперативную панель.

## Ключевая идея

Платформа получает телеметрию с датчиков, автоматически оценивает риски, формирует инциденты и отправляет обновления в интерфейс в реальном времени. Это сокращает время от обнаружения события до реакции.

## Архитектура

- `server`:
  - REST API для аутентификации, пользователей, организаций, устройств, инцидентов, статистики.
  - Prisma ORM и PostgreSQL.
  - Socket.IO для push-событий на клиентов.
  - Сервис водной безопасности (периодический опрос внешнего AI API).
- `client`:
  - React SPA с ролевой навигацией.
  - GIS-интерфейс на MapLibre.
  - Панели мониторинга, карта инцидентов, работа с устройствами и организациями.

## Роли и модель доступа

- `SUPER_ADMIN`: полный доступ по системе.
- `ADMIN`: управление устройствами, пользователями и организациями в разрешенных границах.
- `MCHS_USER`: мониторинг обстановки и управление глобальной тревогой.
- `ORG_OPERATOR`: работа с устройствами своей организации.

## Как проходит событие тревоги

1. Устройство отправляет данные на `POST /api/devices/iot/data`.
2. Backend обновляет состояние устройства и определяет уровень риска.
3. При входе в `DANGER` создается запись инцидента.
4. Клиентам отправляются события `device-update` и `alert` через Socket.IO.
5. Интерфейс карты и панели сразу показывают изменения.

## Модуль водной безопасности

- В фоне работает `waterSafetyService`.
- Сервис опрашивает внешний AI endpoint и публикует `water-alert`.
- На клиенте это отображается как отдельный тревожный слой/оверлей.

## Сильные стороны текущей реализации

- Единая модель данных для организаций, пользователей, устройств и инцидентов.
- Реальное время через сокеты без ручного обновления страницы.
- Гибкая ролевая модель для разных уровней доступа.
- ГИС-инструменты для оперативной оценки и маршрутизации.

## Практическое применение

- Ситуационные центры МЧС.
- Мониторинг критической инфраструктуры.
- Университеты, заводы, склады и другие распределенные объекты.
- Тренировки и учебные сценарии реагирования.
